# 💱 Currency Converter Web App

A modern and interactive **Currency Converter** built using **HTML, CSS, and JavaScript**.  
This project converts currencies between different countries with **real-time exchange rates**, **country flags**, and **currency icons**.

---

## 🌍 Live Demo
🔗 https://asmit2464-dev.github.io/currency-convertor/


---

## ✨ Features
- 🌐 Country-based currency selection
- ⚡ Real-time conversion using Fetch API
- 🎨 Clean & attractive UI
- 📱 Responsive design

---

## 🛠 Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Fetch API**
- **ExchangeRate API**
